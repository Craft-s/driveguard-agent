# DriveGuard Agent 开题报告

## 1．课题介绍

本课题主要研究基于 **Multi-model Visual Perception、Temporal Behavior Analysis 与 Agent-based Decision Making** 的驾驶安全主动干预系统。系统通过车内摄像头采集实时视频流，利用浏览器端 **On-device AI Inference** 完成驾驶员状态感知，并通过多模型证据融合、行为持续性确认和风险决策，将离散检测结果转化为连续风险事件，实现从视觉感知、风险推理到主动干预的完整闭环。

## 2．课题功能

### 基本功能1：多源驾驶行为感知（Multi-source Behavior Perception）

功能描述：融合 **YOLO Driver Behavior Detection、MediaPipe Face Landmark Tracking 与 EfficientDet-Lite0 Object Detection**，实时检测闭眼、低头、视线偏移、抽烟、使用手机及安全带佩戴状态，并通过跨模型证据进行类别冲突裁决。

### 基本功能2：时序风险建模（Temporal Risk Modeling）

功能描述：采用 **Temporal Evidence Aggregation、Event Persistence Threshold 与 Consecutive-frame Confirmation**，综合分析异常行为的持续时间、连续状态及组合关系，并通过加权风险评分动态判断驾驶风险等级，降低单帧波动造成的错误报警。

### 基本功能3：主动干预闭环（Active Intervention Loop）

功能描述：根据实时风险等级触发 **Multi-level Audio-visual Warning**，在高风险状态下调用浏览器语音合成进行中文语音提醒，同时记录异常事件并生成包含安全评分、风险统计和驾驶建议的结构化报告。

## 选做

### 创新功能：可解释驾驶安全智能体（Explainable Driving Safety Agent）

功能描述：基于模型输出、时序状态和风险评分构建可追溯的 **Context-aware Reasoning**，支持用户使用自然语言查询报警原因，并通过 **Evidence-based Explanation** 说明风险事件、触发条件与等级变化依据，形成“感知—分析—决策—干预—反馈”的智能闭环。
